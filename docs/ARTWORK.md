# README artwork

`banner.png` was created with the built-in ImageGen tool on 2026-10-27. It uses the existing RootDrive app icon as a visual reference. The app icon itself was not changed.

Prompt:

> Create a premium GitHub README header banner for RootDrive, an elegant self-hosted file storage app. Wide landscape banner approximately 3.5:1 aspect ratio. Reference image is the existing RootDrive app symbol: three simple 2D hard disks joined by branching roots. Reuse that logical disk-and-roots concept as one understated flat line illustration on the right, in pale slate blue; do not render photorealistic disks or folders. Background deep slate navy #202936 with restrained muted blue #9db7dd, very subtle fine branching lines flowing toward the right edge, quiet editorial composition, generous negative space, crisp graphic design, precise baseline alignment. On the left place oversized beautifully kerned clean modern white sans-serif title, exact text 'RootDrive'. Below it one small understated line, exact text 'Self-hosted file storage'. The RootDrive wordmark is the main visual focus, with a tiny muted blue square punctuation accent. No other text, no badges, no mock browser, no interface screenshot, no 3D, no neon, no lens flare, no watermark. The composition should feel calm, technical, beautifully minimal and match a slate-blue dashboard. Entire banner opaque with clean straight rectangular edges, leave generous safe margins so all lettering and artwork fit comfortably.

`screenshots/` contains real captures of RootDrive, not generated UI. The temporary demo workspace was separate from the user's storage and is not shipped. No personal content or authentication secrets are included.
